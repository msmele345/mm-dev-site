# 02 — Chrome aesthetic

Type: grilling
Status: resolved
Blocked by: none

## Question

What is the base aesthetic for the site chrome — everything around the chameleon tiles
(nav, hero, blog, footer)?

## Answer

**Ink-black + electric lime.** Near-black ground, stark white type, one screaming accent
— electric lime (#C6FF00 territory) — used sparingly for links, hovers, and highlights.
The dark neutral chrome makes every tile's colors detonate, and fits the projects' shared
nocturnal DNA (club, night sky, late-night trading floor). Accent chosen over hot magenta
and cyan: "techno flyer meets terminal phosphor," effortless contrast on black.
Rejected: paper-white brutalist (fights the nocturnal mood), duotone accent-shifter
(scroll complexity everywhere).
