# 07 — Blog authoring

Type: grilling
Status: resolved
Blocked by: none

## Question

How are blog posts authored and presented?

## Answer

**MDX in-repo.** Posts are `.mdx` files committed to the repo — write in the editor,
commit to publish. Full React components inside posts (e.g. embed a mini groovebox demo
in a post about elevated-bpm). First-class code blocks with syntax highlighting.
Rejected: plain markdown (loses interactive embeds), headless CMS (service dependency
for a single-author blog).
