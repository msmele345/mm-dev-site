# 01 — Showcase concept

Type: grilling
Status: resolved
Blocked by: none

## Question

What is the core visual concept for showcasing the projects — the thing that makes the
site "dazzling, high contrast, and poppy"?

## Answer

**Chameleon tiles.** The site chrome is neutral and ultra-high-contrast; each featured
project's card is a mini-world rendered in that project's own visual identity:

- **elevated-bpm** → groovebox faceplate (step-sequencer LEDs, 909-style pads)
- **terminal-one** → trading terminal (scrolling ticker, green phosphor numbers)
- **telescope** → star field (twinkling stars, self-drawing constellation)
- **sound-city** → club flyer (grainy dark poster, neon "TONIGHT" energy)

Tiles come alive on hover/focus (see [10 — Motion policy](10-motion-policy.md)).
Rejected alternatives: poster wall (typographic snap-scroll), immersive scroll chapters
(too heavy), bento grid (too generic).
