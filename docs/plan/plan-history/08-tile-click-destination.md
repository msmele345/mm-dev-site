# 08 — Tile click destination

Type: grilling
Status: resolved
Blocked by: none

## Question

Where does clicking a chameleon tile take the visitor?

## Answer

**A full case-study page per project**, in that project's visual identity: in-theme hero,
the story (problem → build → result), screenshots/GIFs, stack badges, links to repo and
live demo. Gives depth for recruiters/collaborators and a home for projects without
public repos. Rejected: straight out to repo/demo (visitors bounce off-site), expanding
overlay (fights deep-linking/SEO, cramps the story).
