# 02 — Chrome shell

## Parent

Wayfinder map: `/plan/plan-history/map.md`

## What to build

The site chrome around the (not-yet-built) project wall: a nav carrying the MITCH MELE
wordmark, a punchy hero/about section (who Mitch is, what they build), contact links
(GitHub msmele345, email, LinkedIn), and a footer. The wordmark is set huge in the
display face per ADR 0003 — this issue establishes the typographic voice of the whole
site. High contrast, poppy, but neutral enough that the chameleon tiles (later issues)
carry all the color.

## Acceptance criteria

- [ ] Nav with MITCH MELE wordmark; links to home, blog, contact anchors/pages
- [ ] Hero/about section with a short, personality-forward intro
- [ ] Contact links to GitHub, email, and LinkedIn, styled in the lime accent
- [ ] Footer present; layout responsive from mobile to wide desktop
- [ ] Site metadata (title, description) set; keyboard navigation works with visible lime focus states
