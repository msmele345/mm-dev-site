# mm-dev-site

Mitch Mele's portfolio and development blog, built with Next.js App Router and React 19.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

The first live deployment is available at [mm-dev-site.vercel.app](https://mm-dev-site.vercel.app).
